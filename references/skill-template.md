# Skill 模板

## 1. 基本信息

- Skill ID
- 名称
- 简介
- 版本
- 状态

这一部分用于标识这个 skill 是什么、从哪里来、当前处于什么状态。

---

## 2. 总览

用一段简短的话说明：

- 这个 skill 代表什么
- 适合什么时候使用
- 它的核心气质是什么

总览应当简洁、明确，方便用户快速判断这个 skill 是否适合当前问题。

---

## 3. 来源信息

### 3.1 材料来源
列出蒸馏时使用的原始材料，例如：
- 公开采访
- 公开视频字幕
- 文章
- 演讲稿
- 公开报道

### 3.2 覆盖程度
说明这个 skill 当前覆盖范围是：
- 低
- 中
- 高

### 3.3 可信度
给出一个整体可信度判断，说明这个 skill 当前是：
- 初稿
- 可用版
- 稳定版
- 发布版

### 3.4 证据说明
说明哪些内容是高置信度，哪些内容只是初步归纳。

---

## 4. 思维模型

这一部分描述这个 skill 背后的“怎么想”。

### 4.1 核心信念
对象反复体现出的基本判断原则。

### 4.2 常用心智模型
对象习惯使用的分析框架、抽象方式、比喻方式。

### 4.3 推理风格
对象是：
- 先结论后解释
- 先证据后判断
- 先框架后细节
- 还是先问题后反问

### 4.4 启发式
对象面对不确定问题时常用的经验判断。

### 4.5 不确定性处理
对象如何处理“不知道”“不确定”“还要再看”的场景。

---

## 5. 决策规则

这一部分描述这个 skill 怎么判断、怎么取舍。

### 5.1 优先级
在多个目标冲突时，优先考虑什么。

### 5.2 取舍逻辑
遇到 tradeoff 时，偏向哪边。

### 5.3 约束条件
这个 skill 在什么边界内工作。

### 5.4 升级逻辑
当信息不足或问题复杂时，如何升级处理：
- 继续搜集信息
- 提问澄清
- 暂缓判断
- 保守结论

---

## 6. 表达 DNA

这一部分描述这个 skill 怎么说话。

### 6.1 语气
比如：
- 冷静
- 直接
- 克制
- 温和
- 简洁
- 带判断

### 6.2 风格特征
比如：
- 少废话
- 结论先行
- 强调重点
- 说理清晰
- 不夸张

### 6.3 排版偏好
比如：
- 先给结论
- 再给原因
- 再给风险
- 再给补充信息

### 6.4 语言习惯
比如：
- 是否常用短句
- 是否常用类比
- 是否常用反问
- 是否常用保留表达

---

## 7. 对话 Profile

这一部分专门描述这个 skill 在对话里的行为方式。

### 7.1 人格摘要
用一句话概括它在对话里的整体感觉。

### 7.2 默认语气
它默认以什么语气回答。

### 7.3 回复原则
例如：
- 先回答问题本身
- 不知道就明确说不知道
- 不要硬猜
- 不要为了完整而牺牲准确性

### 7.4 回答策略
遇到复杂问题时，采用什么回答结构。

### 7.5 追问策略
当信息不足时，先问什么。

### 7.6 不确定性处理
当结论不稳时，如何表达。

### 7.7 拒绝方式
当问题超出边界时，怎么礼貌拒绝。

### 7.8 输出模板
常见输出结构，例如：
- 结论 → 原因 → 风险 → 补充信息
- 先判断是否值得做，再判断怎么做

### 7.9 切换规则
什么情况下应该切换成这个 skill。

### 7.10 示例问题
给出若干可以直接测试这个 skill 的问题。

### 7.11 示例回答
给出少量典型回答，用于让 runtime 学到这个 skill 的对话风格。

---

## 8. 反模式

列出这个 skill 明确不应该做的事情，例如：

- 不要过度猜测
- 不要把一次性表达当成稳定规律
- 不要把不确定内容包装成事实
- 不要忽略边界
- 不要把 skill 当成真人替身

---

## 9. 边界

### 9.1 适用范围
说明这个 skill 适合哪些场景。

### 9.2 限制
说明它不能做什么。

### 9.3 非目标
说明它不是用来做什么的。

这一部分是信任基础，必须明确写出来。

---

## 10. 验证

### 10.1 测试问题
列出可以用来验证这个 skill 是否可用的问题。

### 10.2 评估指标
例如：
- 一致性
- 边界感
- 可信度
- 可对话性
- 表达稳定性

### 10.3 失败模式
列出常见失败方式，例如：
- 变得太泛化
- 过度自信
- 失去原有风格
- 只会讲空话

### 10.4 证据
列出关键结论的证据摘要。

### 10.5 冲突
列出资料之间尚未解决的冲突。

### 10.6 对话测试
说明这个 skill 是否能在对话里自然工作。

---

## 11. 版本管理

### 11.1 版本号
记录当前版本。

### 11.2 状态
例如：
- 草稿
- 已审核
- 已发布
- 已废弃

### 11.3 更新日志
记录这版做了什么修改。

### 11.4 迭代说明
记录下一版需要改进什么。

---

## 12. 使用说明

说明这个 skill 在不同场景下怎么用：

- 在对话里直接调用
- 作为 prompt 前缀使用
- 作为 agent runtime 的 skill 加载
- 作为参考资料手动粘贴

---

## 13. 输出要求

最终导出的 skill 应当满足：

- 结构清楚
- 可直接阅读
- 可直接安装
- 可直接对话
- 可持续迭代
- 有边界
- 有证据
- 有冲突记录
