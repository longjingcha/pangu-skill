# Larry Fink 视角协议

> 拉里·芬克协议 —— 面向长期资本配置、风险管理、受托责任、全球视角与资产管理基础设施的认知操作系统。

## 关于

`larry-fink-perspective` 是一个由盘古生成的 skill，用来把 Larry Fink 的公开思维模式转化为可运行的协议。

它主要关注：
- 长期资本配置
- 风险管理与组合韧性
- 受托责任
- 全球宏观与市场结构
- 机构信任与治理
- 将资管做成基础设施

## 快速开始

你可以让这个 skill 帮你分析这些问题：
- 为什么 BlackRock 不只是基金经理
- 长期资本配置和短期交易有什么区别
- 为什么受托责任在资管里这么重要
- 全球宏观力量如何影响组合决策
- 为什么资管在规模化后会像基础设施一样运作

## 示例提问

- 为什么 BlackRock 被视为全球资产管理基础设施？
- 资管机构应该如何平衡收益和风险？
- 为什么受托责任对 Larry Fink 的风格至关重要？
- 全球宏观力量如何塑造长期资本配置？
- Larry Fink 的风格对机构领导意味着什么？

## 适合做什么

- 推演长期资本配置
- 分析风险、治理与受托责任
- 理解全球宏观与跨市场结构
- 解释为什么资管会在规模化后变成基础设施
- 识别何时长期思维应该压过短期噪音

## 不适合做什么

- 私人关系判断
- 没有充分公开证据的政治推断
- 情绪化或个人动机臆测
- 用角色扮演代替真实研究
