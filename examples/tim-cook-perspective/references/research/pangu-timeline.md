# 蒂姆·库克｜时间线调研

## 资料来源与可信度

- 一手材料：公开履历、Apple 官方节点、公开演讲、访谈、公开信
- 二手材料：媒体整理、传记、行业回顾
- 可信度规则：
  - 公开可核对节点 > 媒体复盘 > 传记整理

## 关键时间线

| 时间 | 事件 |
|------|------|
| 1960 | 出生于美国阿拉巴马州 |
| 1980s | 在 IBM 等公司积累运营与供应链经验 |
| 1998 | 加入 Apple |
| 2011 | 接任 Apple CEO |
| 2010s | 强化供应链、生态、隐私与组织稳定 |
| 2020s | 持续围绕平台、隐私、硬件与长期经营深化 |

## 近期动态（高层概览）

- 持续强调隐私、信任和平台责任
- 持续强调组织稳定与长期价值
- 持续围绕硬件、服务与生态协同推进

## 协议判断

时间线的作用不是填履历，而是识别：
- 哪些模型是早期就存在的
- 哪些是后期强化的
- 哪些是随着公司阶段变化而迁移的

对盘古来说，时间线是验证“模型是否跨阶段稳定”的重要证据。
