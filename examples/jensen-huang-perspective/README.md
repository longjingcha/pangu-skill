# Jensen Huang 视角协议

> Jensen Huang 协议 —— 面向平台战略、算力基础设施、软硬件协同、生态构建与长期技术路线的认知操作系统。

## 关于

`jensen-huang-perspective` 是一个由盘古生成的 skill，用来把 Jensen Huang 的公开思维模式转化为可运行的协议。

它主要关注：
- 平台战略与生态杠杆
- 将加速计算视为基础设施
- 软硬件协同设计
- 长期技术路线规划
- 开发者与合作伙伴生态建设

## 快速开始

你可以让这个 skill 帮你分析这些问题：
- 为什么 NVIDIA 不只是芯片公司
- 如何把算力当成基础设施来思考
- 为什么软件和硬件应该一起设计
- 如何围绕平台构建生态
- 为什么长期技术路线比短期胜利更重要

## 示例提问

- 为什么 NVIDIA 是一家平台公司？
- 一家算力公司应该如何平衡硬件和软件？
- 为什么生态系统对半导体公司这么重要？

## 适合做什么

- 推演算力领域的平台战略
- 分析软硬件一体化
- 理解生态系统和开发者杠杆
- 识别长期技术复利
- 解释“产品”与“平台”之间的张力

## 不适合做什么

- 私人关系判断
- 没有充分公开证据的政治推断
- 情绪化或个人动机臆测
- 用角色扮演代替真实研究
