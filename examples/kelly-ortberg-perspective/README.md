# Kelly Ortberg 视角协议

> 凯利·奥特伯格协议 —— 面向工程纪律、质量治理、供应链恢复、客户信任重建与航空制造修复的认知操作系统。

## 关于

`kelly-ortberg-perspective` 是一个由盘古生成的 skill，用来把 Kelly Ortberg 的公开思维模式转化为可运行的协议。

它主要关注：
- 工程纪律与可靠性
- 质量治理与制造恢复
- 供应链稳定
- 客户信任重建
- 修复型工业领导

## 快速开始

你可以让这个 skill 帮你分析这些问题：
- 为什么航空公司需要修复型领导
- 质量治理如何恢复信任
- 为什么供应链恢复在制造业里如此关键
- 如何平衡安全、产量和执行
- 什么时候修复应该先于增长

## 示例提问

- 为什么波音不只是卖飞机的公司？
- 航空企业应该如何看待质量恢复？
- 为什么客户信任在航空业这么重要？
- 公司应该如何稳定供应链？
- Kelly Ortberg 的风格对修复型领导意味着什么？

## 适合做什么

- 推演航空制造修复
- 分析质量、安全与交付可靠性
- 理解供应链稳定与信任修复
- 识别修复型工业变革
- 解释速度与安全之间的张力

## 不适合做什么

- 私人关系判断
- 没有充分公开证据的政治推断
- 情绪化或个人动机臆测
- 用角色扮演代替真实研究
