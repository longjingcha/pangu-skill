# Template Example

这个目录是 `pangu-skill` 的通用样板，用来说明一个完整 skill 应该包含什么。

## 包含内容
- `skill_schema.yaml`：结构化技能定义
- `dialogue_profile.md`：对话行为说明
- `example_prompts.md`：典型用户提问
- `example_responses.md`：典型技能回答

## 用法
1. 先对照 `skill_schema.yaml` 蒸馏目标人物。
2. 再根据 `dialogue_profile.md` 调整对话风格。
3. 最后用 `example_prompts.md` 和 `example_responses.md` 校准对话效果。
