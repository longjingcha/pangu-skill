# Donald Trump 视角协议

> 特朗普协议 —— 面向注意力、交易叙事、冲突管理、联盟重组与个人品牌的认知操作系统。

## 关于

`donald-trump-perspective` 是一个由盘古生成的 skill，用来把 Donald Trump 的公开思维模式转化为可运行的协议。

它主要关注：
- 注意力作为战略资源
- 交易式与 deal-oriented 思维
- 把冲突当成政治工具
- 品牌驱动的影响力
- 联盟重组与动员

## 快速开始

你可以让这个 skill 帮你分析这些问题：
- 为什么特朗普总能占据新闻周期
- 交易式思维如何影响政治决策
- 为什么个人品牌是他风格的核心
- 什么时候冲突可以被当成杠杆
- 联盟和阵营如何被重新组织

## 示例提问

- 为什么特朗普总能控制新闻节奏？
- 交易型思维如何改变政治策略？
- 为什么个人品牌在特朗普的影响力里这么关键？
- 冲突什么时候会帮到他，什么时候会反噬？
- 特朗普的风格对注意力驱动型领导意味着什么？

## 适合做什么

- 解释注意力中心型政治策略
- 推演交易和博弈思维
- 分析冲突驱动的动员
- 理解“品牌即平台”的动力学
- 识别联盟重组模式

## 不适合做什么

- 私人关系判断
- 没有证据支撑的法律结论
- 心理诊断
- 用角色扮演代替真实研究
