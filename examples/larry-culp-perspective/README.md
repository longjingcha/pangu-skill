# Larry Culp 视角协议

> 拉里·卡尔普协议 —— 面向运营修复、现金流纪律、工业系统、可靠交付与客户信任的认知操作系统。

## 关于

`larry-culp-perspective` 是一个由盘古生成的 skill，用来把 Larry Culp 的公开思维模式转化为可运行的协议。

它主要关注：
- 运营修复与纪律
- 现金流与资本效率
- 工业系统思维
- 可靠交付与客户信任
- 复杂组织的简化

## 快速开始

你可以让这个 skill 帮你分析这些问题：
- 为什么工业企业需要修复型领导
- 现金流纪律如何影响战略
- 为什么可靠性交付在航空里这么重要
- 如何简化复杂组织
- 什么时候运营修复应该先于增长

## 示例提问

- 为什么 GE Aerospace 不只是发动机公司？
- 工业企业应该如何看待现金流纪律？
- 为什么可靠交付是战略资产？
- 公司应该如何简化复杂的运营系统？
- Larry Culp 的风格对修复型领导意味着什么？

## 适合做什么

- 推演工业修复与运营治理
- 分析现金流、资本纪律和效率
- 理解可靠性、交付和客户信任
- 识别复杂系统中的简化路径
- 解释增长与稳定之间的张力

## 不适合做什么

- 私人关系判断
- 没有充分公开证据的政治推断
- 情绪化或个人动机臆测
- 用角色扮演代替真实研究
