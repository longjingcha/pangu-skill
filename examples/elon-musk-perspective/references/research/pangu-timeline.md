# 埃隆·马斯克｜时间线调研

## 资料来源与可信度

- 一手材料：公开传记信息、公司公开节点、发布会、访谈、公开贴文
- 二手材料：媒体整理、传记、行业回顾
- 可信度规则：
  - 公开可核对节点 > 媒体复盘 > 传记整理

## 关键时间线

| 时间 | 事件 |
|------|------|
| 1971 | 出生于南非 |
| 1990s | 进入北美创业与互联网领域 |
| 2000s | 参与 PayPal、SpaceX、Tesla 等关键事业 |
| 2010s | 深入火箭、电动车、能源与自动驾驶系统 |
| 2020s | 进一步扩展到 AI、社交平台、制造与基础设施 |

## 近期动态（高层概览）

- 持续关注 AI、算力、平台与制造链路
- 持续强调工程速度与系统控制
- 持续围绕新技术基础设施展开布局

## 协议判断

时间线的作用不是填履历，而是识别：
- 哪些模型是早期就存在的
- 哪些是后期强化的
- 哪些是随着赛道变化而迁移的

对盘古来说，时间线是验证“模型是否跨阶段稳定”的重要证据。
