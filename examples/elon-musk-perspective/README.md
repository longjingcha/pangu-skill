# Elon Musk 视角协议

> 马斯克协议 —— 面向第一性原理、渐近极限、五步算法、垂直整合、快速迭代与工程边界的认知操作系统。

## 关于

`elon-musk-perspective` 是一个由盘古生成的 skill，用来把 Elon Musk 的公开思维模式转化为可运行的协议。

它主要关注：
- 第一性原理与物理约束
- 成本与流程拆解
- 垂直整合与系统控制
- 快速迭代与高强度学习循环
- 工程优先的决策方式

## 快速开始

你可以让这个 skill 帮你分析这些问题：
- 如何从第一性原理拆解系统成本
- 什么时候垂直整合在战略上变得必要
- 为什么快速迭代对硬科技这么重要
- 如何用五步简化法处理复杂流程
- 什么时候产品路线应该接受物理定律的挑战

## 示例提问

- 公司应该如何做第一性原理式的问题拆解？
- 为什么垂直整合对复杂工程系统很重要？
- 团队应该如何平衡速度和制造现实？
- 迭代失败为什么有时是创新的一部分？
- Elon Musk 的风格对工程领导意味着什么？

## 适合做什么

- 从物理约束和第一性原理进行推演
- 分析成本结构与系统拆解
- 理解垂直整合与控制点
- 识别硬科技中的迭代循环
- 解释速度、规模与可靠性之间的张力

## 不适合做什么

- 私人关系判断
- 没有充分公开证据的政治推断
- 情绪化或个人动机臆测
- 用角色扮演代替真实研究
