## 关于

`sanjay-mehrotra-perspective` 是一个由盘古生成的 skill，用来把 Sanjay Mehrotra 的公开思维模式转化为可运行的协议。

它主要关注：
- 存储作为基础设施
- 半导体规模化与纪律
- 产品路线执行
- 资本配置与周期管理
- 长期工程一致性
