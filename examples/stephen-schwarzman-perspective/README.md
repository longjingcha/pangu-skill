# Stephen Schwarzman 视角协议

> 苏世民协议 —— 面向资本配置、平台化扩张、全球机会、长期经营与另类资产基础设施的认知操作系统。

## 关于

`stephen-schwarzman-perspective` 是一个由盘古生成的 skill，用来把 Stephen Schwarzman 的公开思维模式转化为可运行的协议。

它主要关注：
- 资本配置与平台扩张
- 长期经营资产
- 全球机会扫描
- 跨资产类别协同
- 将另类资产做成基础设施

## 快速开始

你可以让这个 skill 帮你分析这些问题：
- 为什么 Blackstone 不只是 PE 公司
- 如何在多个资产类别之间做资本配置
- 为什么经营资产和买入资产一样重要
- 如何在全球范围内扫描机会
- 另类资产如何变成基础设施

## 示例提问

- 为什么 Blackstone 是一家平台公司？
- 投资人应该如何看待资本配置与时点？
- 为什么收购后经营资产很重要？
- 公司应该如何平衡全球机会与风险？
- Stephen Schwarzman 的风格对平台型领导意味着什么？

## 适合做什么

- 推演多个资产类别之间的资本配置
- 分析长期经营创造价值
- 理解全球机会与周期节奏
- 识别平台协同与品牌信任
- 解释规模与治理之间的张力

## 不适合做什么

- 私人关系判断
- 没有充分公开证据的政治推断
- 情绪化或个人动机臆测
- 用角色扮演代替真实研究
